# 🐾 PawHub — Roblox Lua GUI Hub

PawHub is a Roblox Lua GUI hub created by me, **iiidjjjmmo**. It brings different tools, settings, and features together in one interface.

## 📦 What's Inside?

- 👁️ **Visuals** — Visual overlays and customizable display settings.
- 🎯 **Aim Settings** — Configurable aim-assist options.
- 🪙 **Coin Collection** — Coin collection and farming features.
- 🏃 **Movement** — Movement-related options and controls.
- ⌨️ **Keybinds** — Shortcuts for supported features.
- ⚙️ **Config System** — Save, load, import, and export settings where supported.
- 🔔 **Notifications & Logs** — Notifications and feedback for different actions.
- 🎨 **Custom GUI** — A single interface to access the available features and settings.

## 🚀 Installation

1. Download or clone the repository.
2. Open the source code and check what's inside.
